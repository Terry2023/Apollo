# 3D Portfolio — Terry Schermerhorn

Real-time 3D, hard-surface modeling, and interactive environments. This repo is the source for my public portfolio — models, scenes, and experiments built in Blender, Unreal, and WebGL.

![Hero Render](./renders/hero.jpg)

## What's inside

- **/models** — production-ready assets (.blend, .fbx, .obj) — vehicles, props, architecture
- **/scenes** — full environments with lighting setups
- **/realtime** — Unreal and Three.js interactive builds
- **/renders** — 4K stills and turntables
- **/breakdowns** — wireframes, UVs, and shader graphs

All work is original unless noted in the file header.

## Focus

- Hard-surface modeling with clean topology
- PBR texturing (Substance Painter / Designer)
- Real-time optimization for games and web
- Lighting as storytelling, not just illumination

## Tech

Blender 5.0, Unreal Engine 5, Lightwave 3D
